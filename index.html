CKD Screening & eGFR Calculator

gcarrill_ckd_screening.py • Healthcare Data Pipeline

Python 3 2021 CKD-EPI

Automated clinical screening workflow parsing patient demographics CSV and Comprehensive Metabolic Panel (CMP) lab JSON data to calculate 2021 CKD-EPI eGFR scores and isolate high-risk renal patients (eGFR ≤ 65) for targeted care management.

Dual Ingestion Reads patient CSV + lab CMP JSON
2021 CKD-EPI Eq Race-free serum creatinine eGFR
Risk Isolation Exports high-risk cohort to results.csv
gcarrill_ckd_screening.py 
import csv
import json

# 1. Read patient demographics from CSV file
demographics = []
with open('patient_demographics.csv', mode='r', encoding='utf-8') as file:
    reader = csv.DictReader(file)
    for row in reader:
        demographics.append(row)

# 2. Read CMP lab results JSON data
with open('cmp.json', mode='r', encoding='utf-8') as file:
    cmp_data = json.load(file)

screening_results = []

# 3. Calculate eGFR using 2021 CKD-EPI Equation
for patient in demographics:
    patient_id = patient['patient_id']
    sex = patient['sex']
    age = float(patient['age'])
    full_name = f"{patient['first_name']} {patient['last_name']}"
    
    if patient_id in cmp_data:
        panels = cmp_data[patient_id]
        serum_creatinine = None
        
        for panel in panels:
            if panel['measure'] == 'Creatinine':
                serum_creatinine = float(panel['patient_measure'])
                break
                
        if serum_creatinine is not None:
            c = 142
            k = 0.7 if sex == 'F' else 0.9
            a = -0.241 if sex == 'F' else -0.302
                
            scr_k = serum_creatinine / k
            low = min(scr_k, 1.0)
            high = max(scr_k, 1.0)
            
            # 2021 CKD-EPI formula execution
            egfr = c * (low ** a) * (high ** -1.200) * (0.9938 ** age)
            if sex == 'F':
                egfr *= 1.012
                
            # Isolate patients with high risk eGFR <= 65
            if egfr <= 65:
                screening_results.append({
                    'patient_id': patient_id,
                    'patient_name': full_name,
                    'mobile_phone': patient['mobile_number'],
                    'eGFR': round(egfr, 2)
                })

# Output high-risk cohort to results.csv
print(f"Screening complete! {len(screening_results)} patients identified.")

-- CHIP732_Week06_SQL1_lab1.sql
-- Patient demographics & Race distribution
SELECT patient_race, COUNT(*) AS CNT
FROM patient
WHERE 1=1
GROUP BY patient_race
ORDER BY CNT DESC;

-- Patient encounters by primary location & department
SELECT 
    CASE WHEN primary_loc = '' THEN 'UNKNOWN' ELSE primary_loc END AS loc,
    department_name,
    COUNT(*) AS total_encounters,
    COUNT(DISTINCT random_pat_enc_csn_id) AS unique_encounters
FROM PatientEnc
GROUP BY loc, department_name
ORDER BY total_encounters DESC;
-- CHIP732_Week06_SQL1_lab2.sql
-- Concatenate encounters for a specific patient
SELECT random_pat_id, GROUP_CONCAT(disp_enc_type) AS encounter_list
FROM patientEnc
WHERE random_pat_id = '0x01C4ADB0E7AF'
GROUP BY random_pat_id;

-- Identify patients with exactly 5 unique diagnosis codes
SELECT random_pat_id, random_pat_enc_csn_id,
       COUNT(*) AS total_codes,
       COUNT(DISTINCT code) AS unique_codes,
       GROUP_CONCAT(code) AS dx_codes
FROM allDiagnosis
GROUP BY random_pat_id, random_pat_enc_csn_id
HAVING unique_codes = 5
ORDER BY total_codes DESC;
-- CHIP732_Week06_SQL2_lab3.sql
-- JOIN Patient & Encounter tables with appt status filter
SELECT DISTINCT a.random_pat_id, a.gender
FROM patient a
LEFT JOIN patientEnc b ON a.random_pat_id = b.random_pat_id
WHERE b.appt_status = 'Completed';

-- Nested SQL View calculation for gender percentages
DROP VIEW IF EXISTS patient_cnt;
CREATE VIEW patient_cnt AS
SELECT gender, COUNT(*) AS cnt, (SELECT COUNT(*) FROM patient) AS tot
FROM patient
GROUP BY gender;

SELECT gender, ROUND(cnt * 1.0 / tot, 4) AS percentage FROM patient_cnt;

-- Relational Schema with Foreign Keys & Constraints
CREATE TABLE student_course (
    seq INT PRIMARY KEY,
    s_id INT,
    c_id TEXT,
    FOREIGN KEY (s_id) REFERENCES student (s_id),
    FOREIGN KEY (c_id) REFERENCES course (c_id)
);

-- Aggregate Left Join across Teachers & Courses
SELECT a.t_id, last_name || ', ' || first_name AS name, COUNT(*) AS course_count
FROM teacher a
LEFT JOIN teacher_course b ON a.t_id = b.t_id
GROUP BY a.t_id, name
ORDER BY course_count DESC;

Library of Babel Algorithmic Simulation

library_of_babel_gcarrill.py • Multi-nested Logic

5-Level Nested Loop

Multi-nested looping structure simulating Jorge Luis Borges' Library of Babel concept. Algorithms systematically construct rooms, bookshelves (5 per room), books (32 per shelf), pages (410 per book), and lines (40 lines of 80 characters each) from a 28-character set.

library_of_babel_gcarrill.py 
import random

characters = "abcdefghijklmnopqrstuvwxyz. "
room = []

# 5-Level Nested Loop Architecture
for shelf_count in range(5):
    bookshelf = []
    for book_count in range(32):
        book = []
        for page_count in range(410):
            page = []
            for line_count in range(40):
                line = ""
                for char_count in range(80):
                    line += random.choice(characters)
                page.append(line)
            book.append(page)
        bookshelf.append(book)
    room.append(bookshelf)

print(room)
